What the app does - FamousBRestaurant is a native Android ordering app built for an African cuisine restaurant. It lets customers browse the menu, place orders, book tables, earn loyalty points, and leave reviews all from their phone. It also includes an admin dashboard for managing the restaurant side of things.
what the app does
Kotlin - primary language
Firebase - backend (Authentication, Firestore/Realtime Database, Storage)
Android Studio - IDE
AI chatbot integration for customer support
Main features
AI chatbot for customer queries
Reviews and ratings
Loyalty points system
Favourites
Table booking
Admin dashboard for managing orders, menu, and bookings
Dark gold themed UI across ~29 screens

How to run it
https://github.com/edenhon7/FamousBRestaurant
Open the project in Android Studio.
Connect your Firebase project and add your own google-services.json to the app/ directory.
Sync Gradle and allow the required dependencies to install.
Run the app on an Android emulator or physical Android device.
